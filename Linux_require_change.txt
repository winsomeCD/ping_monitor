================================================================================
Linux / Ubuntu Deployment Guide & Required System Changes
Ping Check Enhanced — High-Performance Network Monitor
================================================================================

This document details the system requirements, kernel settings, and configuration
changes needed to run this monitor with optimal performance and zero packet drops
on an Ubuntu / Linux machine.

--------------------------------------------------------------------------------
1. Why Run on Linux / Ubuntu?
--------------------------------------------------------------------------------
When running on Linux, the monitor automatically activates the native compiled C
"fping" engine instead of Python raw sockets:
- Zero Python GIL overhead: Network I/O, checksum calculations, and hardware 
  packet transmission are handled in compiled C kernel event loops (epoll).
- Perfect packet pacing: Eliminates the "thundering herd" microburst problem by 
  pacing packets across the interval window via fping's "-i" flag.
- Near-zero CPU utilization: Python simply reads structured JSON events emitted 
  by fping rather than handling hundreds of concurrent network futures.
- No socket reply collision: The Linux network stack routes ICMP echo replies 
  directly without the broadcast duplication overhead present in Windows.

--------------------------------------------------------------------------------
2. Required Linux System Configuration (One-Time Setup)
--------------------------------------------------------------------------------

Step 1: Install Native fping (Version 5.0+)
------------------------------------------
Run in your Ubuntu terminal:
    sudo apt update
    sudo apt install -y fping

Verify version (must be >= 5.0 with JSON support):
    fping -v
    fping -h | grep -i json

Step 2: Enable Non-Root Unprivileged ICMP Sockets
-------------------------------------------------
By default, standard non-root users cannot open raw sockets. Enable ICMP group
range so standard users can ping without sudo:

Temporary (immediate):
    sudo sysctl -w net.ipv4.ping_group_range="0 2147483647"

Permanent (survives system reboots):
    echo 'net.ipv4.ping_group_range = 0 2147483647' | sudo tee -a /etc/sysctl.conf
    sudo sysctl -p

Step 3: Install Python Dependencies
-----------------------------------
In your virtual environment or system Python:
    pip install -r requirements.txt
or via Ubuntu apt packages:
    sudo apt install -y python3-pyside6 python3-openpyxl
    pip install icmplib

--------------------------------------------------------------------------------
3. Key Linux Improvements Implemented in probes.py
--------------------------------------------------------------------------------
The codebase in ping_monitor/ is already optimized for Linux with the following:

A. Dynamic Packet Gap Calculation (-i flag):
   In probes.py (_run_fping):
   - Computes: send_gap_ms = min(10, requested_period_ms // target_count)
   - For 500 hosts and a 1.0s interval, sets "-i 2" (2 ms between packet dispatches).
   - Prevents fping from defaulting to its slow 25 ms interval (which stretched 
     a 500-host scan to 12.5 seconds).
   - Command line generated by probes.py:
     fping --json --loop --size <bytes> -i <gap_ms> --period <ms> --timeout <ms> --retry 0

B. Upfront DNS Pre-Resolution (DNSResolver.pre_resolve_all):
   - Pre-resolves all 500 domains concurrently before the probe loop starts.
   - Leverages Ubuntu's local systemd-resolved (127.0.0.53) caching daemon.
   - Eliminates DNS thread pool bottlenecks during real-time ping cycles.

C. Automatic Dual-Engine Fallback:
   - If fping is found with JSON support -> uses high-speed native fping.
   - If fping is missing -> seamlessly falls back to AsyncICMPSession (4MB buffer).

--------------------------------------------------------------------------------
4. How to Run on Ubuntu
--------------------------------------------------------------------------------
Desktop GUI mode:
    python3 ping_monitor.py

Headless / Unit test verification:
    python3 -m unittest discover tests
